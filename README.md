## 📖 Panduan Hosting Gratis di GitHub Pages

Website ini adalah **Static Site** (HTML, CSS, JS murni), sehingga dapat di-hosting **100% GRATIS selamanya di GitHub Pages** dengan SSL/HTTPS otomatis!

### Opsi A: Cara Cepat Melalui Web Browser GitHub (Tanpa Perlu Terminal)
1. **Buat Akun / Login ke GitHub**:
   - Kunjungi [github.com](https://github.com) dan login ke akun Anda.
2. **Buat Repository Baru**:
   - Klik tombol hijau **New** (atau ikon `+` di kanan atas -> **New repository**).
   - Beri nama repository, misalnya: `reka-saujana-falah` (atau `<username-anda>.github.io` jika ingin menjadi domain utama akun).
   - Pilih opsi **Public**.
   - Centang opsi *Add a README file* (atau biarkan kosong).
   - Klik **Create repository**.
3. **Unggah File Website**:
   - Di halaman repository baru Anda, klik tombol **Add file** -> **Upload files**.
   - Tarik (drag & drop) seluruh isi folder proyek:
     - `index.html`
     - folder `assets/` (yang berisi `css/`, `js/`, dan `images/`)
   - Tunggu proses upload selesai.
   - Tulis pesan commit (contoh: `Initial release company profile`) lalu klik tombol hijau **Commit changes**.
4. **Aktifkan Fitur GitHub Pages**:
   - Masuk ke tab **Settings** di repository Anda.
   - Di menu sebelah kiri, klik menu **Pages** (pada bagian *Code and automation*).
   - Pada bagian **Build and deployment**:
     - *Source*: pilih **Deploy from a branch**.
     - *Branch*: pilih branch `main` (atau `master`), folder `/ (root)`.
     - Klik tombol **Save**.
5. **Selesai! Website Anda Sudah Online**:
   - Tunggu sekitar 1–2 menit.
   - Refresh halaman **Settings -> Pages**. Anda akan melihat tautan website yang aktif:
     `https://<username-anda>.github.io/reka-saujana-falah/`

## 🌐 Tips Menggunakan Custom Domain Sendiri (Opsional)
Jika Anda nanti membeli domain sendiri (misalnya `rekasaujanafalah.com` atau `rekasaujanafalah.id`):
1. Beli domain di registrar lokal/internasional (Niagahoster, Domainesia, Namecheap, Cloudflare, dll).
2. Di GitHub Repository -> **Settings** -> **Pages** -> kolom **Custom domain**, masukkan nama domain Anda (contoh: `rekasaujanafalah.com`).
3. Di DNS Management registrar domain Anda:
   - Tambahkan CNAME record: `www` mengarah ke `<username-anda>.github.io`.
   - Atau 4 buah A record untuk apex domain yang mengarah ke IP GitHub Pages:
     - `185.199.108.153`
     - `185.199.109.153`
     - `185.199.110.153`
     - `185.199.111.153`
4. Centang **Enforce HTTPS** di GitHub Pages.
