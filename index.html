PERTANYAAN UMUM

Tanya Jawab Seputar LuminaTweak Glass

Mengapa LuminaTweak tidak tersedia di Mac App Store?

Apple secara ketat melarang aplikasi Mac App Store untuk menjalankan perintah defaults write atau memodifikasi file konfigurasi plist sistem demi kebijakan sandbox. Mendistribusikan aplikasi secara langsung via berkas DMG adalah satu-satunya metode resmi untuk memberikan Anda kendali penuh atas optimasi performa macOS.

Bagaimana cara membuka aplikasi pada instalasi pertama kali?

Karena didistribusikan di luar App Store, macOS akan memunculkan dialog Gatekeeper standar pada peluncuran pertama. Cukup Klik Kanan (atau Control + Klik) ikon LuminaTweak Glass di folder Applications, lalu pilih 'Open' (Buka). Anda hanya perlu melakukannya satu kali!

Apakah aplikasi ini aman dan tidak akan merusak macOS saya?

Sangat aman. LuminaTweak Glass 100% mematuhi arsitektur keamanan macOS (SIP-Safe). Kami hanya menggunakan API resmi Apple (defaults write dan killall), tanpa pernah memodifikasi kernel extensions (kext) atau partisi terproteksi. Selain itu, setiap tweak dilengkapi tombol 1-Click 'Kembalikan ke Setelan Bawaan Pabrik'.

Bisakah saya memindahkan lisensi jika membeli laptop Mac baru?

Ya, tentu saja! Anda dapat dengan mudah menonaktifkan lisensi pada Mac lama dan mengaktifkannya di Mac baru langsung melalui menu lisensi di dalam aplikasi sesuai kuota lisensi yang Anda beli.
